# 은행 예·적금 상품 조건 분석 MVP

공개된 은행 예·적금 상품설명서, 약관 또는 금리표의 텍스트를 분석해 **금리와 우대조건**, **수수료**, **중도해지 조건**과 원문 근거를 보여주는 로컬 웹 프로그램입니다. 기존 개인정보 문서 분석 화면과 CLI도 유지합니다.

분석은 OpenAI API를 사용하므로 API 이용 권한, 네트워크 연결과 사용 비용이 필요합니다. 입력한 문서는 OpenAI에 전송됩니다. 실제 개인정보를 입력하지 마세요.

## 실행 준비

- Python 3.10 이상. Python 표준 라이브러리만 사용하므로 별도 패키지 설치나 `pip install`은 필요하지 않습니다. 아래 검증은 Python 3.14.3에서 실행했습니다.
- 사용할 수 있는 OpenAI API 키와 모델 접근 권한. 예시 모델은 `gpt-4.1-mini`입니다.
- 웹 브라우저. 아래 명령은 Windows PowerShell 기준입니다.

프로젝트를 내려받은 뒤 PowerShell에서 **`web.py`가 있는 프로젝트 루트**로 이동하세요. 예를 들어 프로젝트 폴더를 파일 탐색기에서 열고 주소 표시줄에 `powershell`을 입력하면 해당 폴더에서 PowerShell을 열 수 있습니다.

## API 설정과 서버 실행

프로젝트 루트에 `.env` 파일을 만들고 다음 두 항목을 설정합니다. 첫 번째 값은 실제 발급받은 키로 교체하세요. 키를 채팅이나 공개 저장소에 올리지 마세요.

```dotenv
OPENAI_API_KEY=여기에_발급받은_API_키
OPENAI_MODEL=gpt-4.1-mini
```

PowerShell에서 `notepad .env`로 파일을 만들거나 열 수 있습니다. `OPENAI_API_KEY`와 `OPENAI_MODEL`이 실행 환경에도 설정되어 있다면 환경 변수의 값이 `.env`보다 우선합니다. `.env`와 키 파일은 `.gitignore`에 포함되어 있습니다.

같은 폴더에서 서버를 실행합니다.

```powershell
python .\web.py
```

브라우저에서 **http://127.0.0.1:8000/products** 를 엽니다. 서버를 종료하려면 실행 중인 PowerShell에서 `Ctrl+C`를 누릅니다. 주소가 열리지 않으면 서버가 실행 중인지와 8000번 포트를 다른 프로그램이 사용 중인지 확인하세요. 이 서버는 로컬 주소에서만 접근하도록 구성되어 있습니다.

## 상품 분석 사용법

1. 분석할 상품명을 입력합니다.
2. 문서 이름, 같은 상품의 상품명, 입력 범위를 선택하고 공개 문서의 **텍스트**를 붙여 넣습니다. 같은 상품의 문서는 최대 6개까지 추가할 수 있습니다.
3. `상품 분석하기`를 누릅니다. 상품 분석 1건은 OpenAI Chat Completions 요청 1회이며 자동 재시도나 항목별 추가 호출은 없습니다.
4. 세 결과 카드에서 핵심 내용과 확인 상태를 살펴봅니다. 기간별 금리·계산식과 문단별 원문 근거는 펼쳐 볼 수 있습니다.

문서 본문의 합계는 **10,000자 이하**여야 합니다. 프로그램은 긴 문서를 자동으로 자르지 않습니다. PDF 업로드나 PDF 텍스트 추출 기능은 제공하지 않으므로 텍스트와 표의 행·열 관계를 사용자가 미리 확인해야 합니다. 입력 범위를 `전문`으로 선택해도 원본 전체 여부를 검증하지 않습니다. 상품명 일치만으로 문서가 같은 상품에 속한다는 보장도 없습니다.

`rules/`의 네 파일에 있는 76개 규칙을 고정 지시문으로 전달하고 문서는 별도 사용자 메시지에 넣습니다. 구조화된 응답의 문서·문단 ID로 서버가 입력 원문을 가져오며, 존재하지 않는 ID는 근거로 받아들이지 않습니다. 원문과 문단이 일치해도 해당 설명의 의미나 조건의 완전성이 증명되는 것은 아닙니다. 우대조건의 필수 정보가 없거나 원문과 대조되지 않는 경우 추가 확인이 필요합니다. 일부 정형 표와 원문 표현만 구조화하므로 표시되지 않은 조건도 반드시 원문에서 확인하세요.

일반 수수료가 확인되지 않았다는 표시는 무료라는 뜻이 아닙니다. 부분 완료, 추가 확인 필요, 근거 검증 실패와 분석 실패를 구분해 표시합니다. 이 프로그램은 금융상품 추천이나 현재 적용 금리의 보증을 제공하지 않습니다.

상품 분석은 코드에 한도가 등록된 모델만 허용합니다. `gpt-4.1-mini`, `gpt-4.1`, `gpt-4o-mini`, `gpt-4o`와 코드에 명시된 스냅샷을 지원합니다. 요청의 UTF-8 바이트를 이용한 보수적 추정으로 모델 문맥 한도와 출력 한도를 호출 전에 확인합니다. 정확한 토크나이저 계산은 아닙니다.

웹 서버는 요청 본문, 결과 및 API 키를 운영 로그에 기록하거나 결과 파일로 저장하지 않습니다. 키는 서버에서만 사용합니다.

## Vercel 배포

`app.py`는 기존 분석 함수를 재사용하는 Vercel용 WSGI 진입점입니다. GitHub 레포지토리를 Vercel의 개인용 Hobby 플랜에 연결한 뒤 프로젝트 환경변수로 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 설정하세요. 키는 GitHub나 브라우저에 넣지 않습니다. Vercel 환경변수 변경은 새 배포부터 적용됩니다.

배포 주소의 `/products`에서 상품 분석을 사용할 수 있습니다. 분석 요청에는 OpenAI API 비용이 발생하며, 공개 사이트에서는 다른 방문자의 분석도 설정한 계정에 청구됩니다. 브라우저의 중복 클릭 방지와 서버 인스턴스별 동시 실행 방지는 여러 서버 인스턴스 전체의 사용량 제한을 보장하지 않습니다.

시연 주소: https://ax-terms-analysis-sea.vercel.app/products

현재 운영 환경은 GitHub의 `deploy-vercel` 브랜치를 추적합니다. 해당 브랜치에 변경을 올리면 Vercel이 배포하며, `main` 브랜치는 별도로 유지합니다.

`tests/run_hosted_browser_mock.py`는 배포용 서버의 브라우저 화면을 모의 응답으로 확인합니다. 기존 로컬 서버와 CLI 사용법은 동일합니다.

## 기존 개인정보 문서 분석

같은 서버의 **http://127.0.0.1:8000/** 에서 개인정보 문서 분석 화면을 사용할 수 있습니다. `sample.txt`는 이 기능을 위한 공개 개인정보 문서의 시험 입력이며 예·적금 상품설명서가 아닙니다. 원본은 [하나은행 공개 문서 PDF](https://image.kebhana.com/cont/customer/customer07/customer0701/customer070106/__icsFiles/afieldfile/2025/08/20/3-08-1294.pdf)입니다.

동일한 `.env` 또는 환경 변수 설정을 사용해 CLI로 실행할 수도 있습니다.

```powershell
python .\analyze.py .\sample.txt
```

이 CLI는 개인정보 관련 6개 항목의 결과를 화면과 기본 `result.json`에 출력합니다. `--output`으로 다른 결과 파일을 지정할 수 있습니다. 결과 파일과 화면 출력에는 원문 인용이 포함됩니다. 오류가 발생하면 기존 결과 파일이 남아 있을 수 있으므로 성공 여부와 수정 시각을 확인하세요. `--audit audit.json`을 지정하면 응답 ID 등 호출 메타데이터를 별도 파일에 저장합니다. 이 CLI 결과 저장 방식은 상품 분석 웹 화면과 다릅니다.

## 테스트

프로젝트 루트에서 다음 명령을 실행합니다. 테스트는 모의 응답을 사용하며 실제 OpenAI API를 호출하지 않습니다.

```powershell
python -m unittest discover -s tests -v
```

브라우저 검사도 실행하려면 Node.js 22 이상과 Windows용 Google Chrome이 필요합니다. 테스트 스크립트는 `C:\Program Files\Google\Chrome\Application\chrome.exe`를 사용합니다. 다음 명령에는 `--live`를 추가하지 마세요.

```powershell
python .\tests\run_browser_mock.py
```

2026-11-27 검증 환경에서는 Python 3.14.3으로 **65개 테스트 통과**, Node.js 24.14.1과 Chrome으로 **브라우저 검사 통과**를 확인했습니다. 일부 회귀 테스트는 Git에서 제외된 로컬 저장 API 응답이 있을 때만 실행되므로, 새로 내려받은 프로젝트에서는 해당 테스트가 건너뛰어질 수 있습니다. 테스트 통과만으로 실제 문서에 대한 분석 정확성이 보장되지는 않습니다.

## 주요 파일

- `product_analysis.py`: 상품 분석 요청 조립, 단일 API 호출 및 근거 처리
- `rules/`: 공통·금리·수수료·중도해지 분석 규칙
- `web.py`, `web_static/`: 로컬 서버와 웹 화면
- `analyze.py`, `sample.txt`: 기존 개인정보 문서 분석 CLI와 시험 문서
- `tests/`: 모의 응답 기반 Python·브라우저 테스트와 가상 상품 문서
- `docs/`, `test_data/`: 기획 및 문서 검증 자료
- `artifacts/`: 로컬 분석·검증 산출물. Git 추적에서 제외됩니다.
