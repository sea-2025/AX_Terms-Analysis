# 우리은행 저장 응답의 화면 표시 확인

> 이 보고서는 저장된 응답을 재생한 당시의 화면 기록입니다. 이후 원문 근거 연결과 일부 결과 표시가 수정됐으므로 현재 화면과 차이가 있을 수 있습니다.

실제 API를 추가 호출하지 않고 저장된 응답을 모의 재생해 브라우저에서 확인했다. 아래는 화면의 기본 접힘 상태에서 확인한 결과 문구이며, 세부 표는 아래에 별도로 적었다. 원문 근거는 기본적으로 접혀 있다.

## 공통 표시

```text
부분 완료
원문과 적용 조건을 추가 확인해 주세요. 검증되지 않은 AI 설명은 표시하지 않습니다.
상품명: 우리 첫거래우대 정기예금 · 입력 문서 1개. 사용자 입력 범위만 분석하며 원본 전체와 동일 상품 여부를 보증하지 않습니다.
```

## 금리와 우대조건

```text

원문 근거 확인

기준일과 다른 적용 조건·예외는 원문에서 추가 확인해 주세요.

상세 조건·원문 근거 보기 · 4개

추가 확인할 원문 보기 · 1개

근거 검증 실패
근거 검증에 실패해 이 사실을 표시하지 않습니다.

추가 확인 필요
적용 조건과 예외는 원문에서 확인해 주세요.
관련 조건과 예외가 모두 포함됐는지 추가 확인해 주세요.
원문에 적힌 조건이에요. 우대 상한과 동의 조건도 함께 확인해 주세요.
① 신규 직전년도 말일 기준 우리은행 계좌를 보유하지 않은 경우 – 연 1.0%p
② 신규 직전 1년주1)간 우리은행 예·적금(입출금 제외) 상품을 보유하지 않은 경우 – 연 0.4%p
③ 우리 오픈뱅킹 서비스주2)를 가입 및 만기해지시점까지 유지한 경우 – 연 0.4%p
상세 조건·원문 근거 보기 · 2개

추가 확인 사항
입력에서 확인되지 않은 내용과 적용 조건을 원문에서 추가 확인해 주세요.
```

## 수수료

```text
수수료
입력한 상품설명서에서 일반 가입·해지 수수료에 대한 정보를 자동으로 확인하지 못했어요.
수수료가 없거나 무료라는 뜻은 아니에요. 특정 조건에 따른 비용은 원문을 따로 확인해 주세요.

원문 근거 확인
위법계약 해지에는 정해진 조건에 따른 비용 제한이 있어요.
은행이 금융소비자 보호에 관한 법률을 위반해 계약을 체결한 경우에 해당해요.
위반을 안 날부터 1년 이내, 계약일부터 5년 이내이고 계약이 끝나기 전이어야 해요.
은행은 요구받은 날부터 10일 이내에 수락 여부를 알리거나 거절 사유와 함께 거절해야 해요.
은행이 정당한 사유 없이 해지 요구를 따르지 않아 계약을 해지하면 수수료·위약금 등 비용을 요구할 수 없어요.
원문 인용과 위치를 확인했어요. 다른 조건과 예외는 추가 확인해 주세요.
상세 조건·원문 근거 보기 · 2개

추가 확인 사항
입력에서 확인되지 않은 내용과 적용 조건을 원문에서 추가 확인해 주세요.
```

## 펼친 기본금리 표

```text
6개월 이상 1년 미만 가입하면 기본금리는 연 2.60%예요.
1년 이상 2년 미만 가입하면 기본금리는 연 2.80%예요.
2년 이상 3년 이하 가입하면 기본금리는 연 2.20%예요.
```

## 펼친 중도해지 표

```text
3개월 미만: 연 0.1%
3개월 이상 6개월 미만: 기본이율×50%×보유일수/계약일수 · 최저이율 연 0.15%
6개월 이상 9개월 미만: 기본이율×70%×보유일수/계약일수 · 최저이율 연 0.15%
9개월 이상 11개월 미만: 기본이율×80%×보유일수/계약일수 · 최저이율 연 0.15%
11개월 이상: 기본이율×90%×보유일수/계약일수 · 최저이율 연 0.15%
```

이 저장 응답은 우대조건 관련 인용 한 건과 날짜 근거가 실패했으므로 부분 완료다. 우대 상한과 마케팅 동의의 완전한 설명은 확정 표시되지 않는다. 다른 형식의 표와 표현을 모두 인식하는 것도 보장하지 않는다.
