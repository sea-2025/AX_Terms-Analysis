추가 API 호출 없이 기존 `result_woori.json`과 `input_verified.txt`를 현재 후처리에 넣어 확인했다. 이전 상태는 `offline_diagnosis.md`에 기록된 일괄 추가 확인 처리 기준이다.

## 실제 브라우저에 표시된 내용

저장된 응답을 **모의 응답**으로 재생해 브라우저에서 실제 텍스트를 확인했다. 결과의 해당 사실에는 `원문 확인`이 표시되고, 아래 내용과 함께 `기준일과 다른 적용 조건·예외는 원문에서 추가 확인해 주세요.`가 보인다.

> 원문 표: 6개월 이상 12개월 미만: 연 2.60%; 12개월 이상 24개월 미만: 연 2.80%; 24개월 이상 36개월 이하: 연 2.20%

> 원문 표: 3개월 미만: 연 0.1%; 3개월 이상 ~ 6개월 미만: 기본이율×50%×보유일수/계약일수 (최저이율 연 0.15%)

나머지 6개월 이상·9개월 이상·11개월 이상 구간도 각 행의 산식과 최저이율로 표시된다. 원문 근거는 항목별로 펼칠 수 있다. `원문 확인`은 표시된 표의 연결 관계에 대한 것이며 문서 전체 조건을 모두 확인했다는 뜻이 아니다.

## 판정 방식과 한계

- 기본금리는 `구분 | 기간...` 형태의 기간별 제목과 바로 다음 `기본금리` 또는 `기본이율` 행의 열 수가 같고 각 셀의 형식이 맞을 때만 연결한다.
- 중도해지는 `보유기간 | 이율 | 비고` 표의 연속된 행에서 같은 행의 기간·이율 또는 산식·최저이율을 연결한다. 다른 문단에서 숫자와 기간만 각각 찾아 결합하지 않는다.
- AI의 자유형 설명과 조건을 정답으로 신뢰하지 않는다. 일치 인용은 원문 발췌로 보여주고 해석과 누락 여부는 추가 확인으로 남긴다. 확인 가능한 표 형식이 아니면 구조화하거나 연결하지 않는다.
- 자동으로 모델의 모든 모순이나 모든 누락을 판별하지 못한다. 다른 표 형식, 여러 문서 간 시점과 조건 차이, 표 밖 각주·특약은 여전히 사람이 대조해야 한다.

Python 테스트 49개와 저장 응답 재생을 포함한 로컬 모의 브라우저 검사가 통과했다. 테스트 및 검증 중 실제 API 호출은 0회였다.
