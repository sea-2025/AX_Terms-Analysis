# 상품설명서 입력 텍스트 비교 보고서

작성일: 2026-11-26. 기준은 이 폴더의 `original.pdf`다. 기존 `input.txt`는 변경하지 않았고 별도 `input_verified.txt`를 작성했다. 이 파일은 PDF를 바탕으로 한 **구조 정리본**이며 PDF의 물리적 레이아웃을 그대로 옮긴 파일은 아니다. 규칙과 분석 코드를 수정하거나 API를 호출하지 않았다.

## 변경 내역

| PDF 위치 | 변경 내용 |
|---|---|
| 1쪽 거래조건 | 떨어져 나열된 상품유형·거래방법·가입금액·계약기간·기본금리 제목을 해당 내용에 맞게 재배치했다. 기본금리 표는 기간 세 열과 금리 세 열의 순서가 명확하도록 `|`로 구분했다. |
| 2쪽 우대이율 | 우대이율 본문에 끼어 있던 `중도해지이율` 표제를 실제 중도해지 본문 앞으로 이동했다. ②의 우대율 `연 0.4%p`를 해당 조건과 같은 줄에 놓았다. ①, ③, 최대 연 1.0%p 및 마케팅 동의 조건은 유지했다. |
| 2쪽 중도해지이율 | 기간·산식·비고를 `|`로 구분했다. 원래 3개월 이상 네 행에 걸쳐 있던 병합 셀 `최저이율 연 0.15%`를 각 행에 표시하기 위해 같은 셀의 문구를 세 번 반복했다. 3개월 미만 행에는 붙이지 않았다. 이는 원문에 새로운 조건을 더한 것이 아니라 병합 셀을 평탄화한 것이다. |
| 3쪽 | 만기 후 이율 표에 잘못 끼어 있던 `만기이자 산출근거` 제목을 해당 산식 앞으로 옮겼다. 예금자보호 여부 및 계약해지방법의 행 제목과 내용도 정렬했다. |
| 6쪽 | 용어 표의 `출연` 표제를 질권설정 설명 중간에서 해당 용어 설명 앞으로 옮겼다. |

문장과 수치의 삭제를 피하기 위해 페이지별로 공백·구분자 `|`를 제외한 문자 구성을 비교했다. 모든 페이지에서 원래 문자는 유지됐고, 추가된 원문 문자는 2쪽 병합 셀 문구를 세 번 반복한 것뿐이다. 이 문자 개수 검사는 문장의 순서와 의미가 맞는지까지 보장하지 않으므로, 위 행·열 관계는 PDF 화면을 따로 대조했다.

정리 전후 모두 페이지 구분자 `\f` 6개와 기존 분석기가 빈 줄로 나누어 부여하는 문단 ID 72개를 유지했다. PDF와 기존 입력에 인쇄된 `P0001` 등의 문단 번호가 있던 것은 아니다. 일부 표제와 ②의 금리가 기존 문단 사이에서 이동했으므로 **같은 문단 ID라도 내용과 인용 위치가 바뀐 곳이 있다**. 특히 이전 분석 결과의 인용 ID를 새 입력에 그대로 재사용하면 안 된다. 원래 입력의 P0018은 페이지 경계를 포함하며 이 배치도 유지했다.

## PDF에서 직접 확인한 주요 관계

- 1쪽: 세전 기준일 2026.9.11의 기본금리 행에서 6개월 이상~12개월 미만 연 2.60%, 12개월 이상~24개월 미만 연 2.80%, 24개월 이상~36개월 이하 연 2.20%가 각각 연결된다. 신규일 또는 재예치일에 고시한 계약기간별 이자율 적용 문구도 유지했다.
- 2쪽: 우대조건 ① 연 1.0%p, ② 연 0.4%p, ③ 연 0.4%p, 최대 연 1.0%p. 마케팅 동의는 전화(휴대폰)나 SMS 중 하나 이상에 동의하고 만기해지시점까지 유지하는 조건이다. 중도해지 계좌에는 우대이율을 적용하지 않는 문구와 주1의 기간 정의도 유지했다.
- 2쪽: 3개월 미만 연 0.1%, 그 이후 기간별 기본이율에 50%·70%·80%·90%와 보유일수/계약일수를 곱하는 산식이 각각 표에 연결된다. 최저 연 0.15% 병합 셀은 3개월 이상 네 산식 행에 걸쳐 있다.
- 3쪽: 만기 후 이율은 2쪽 중도해지이율과 별도 표다. 만기 후 경과기간별 약정이율 50%·30%·20%와 각 기간, 약정이율 정의를 유지했다.

## 확인이 더 필요한 범위

- 2쪽 산출근거의 그래프는 그림이라 `input.txt`에서 텍스트로 완전히 추출되지 않았으며, 정리본에도 그림을 새로 묘사하거나 분석 대상으로 추가하지 않았다. 관련 산식은 같은 쪽의 표에 존재한다.
- `original.pdf`의 표시된 조건과 표를 대조했지만 PDF의 배포처 진위와 현재 적용 금리는 확인하지 않았다. PDF에 언급된 별도의 자동재예치 서비스 이용약관도 이 입력에는 포함되어 있지 않아 그 약관의 구체적 이율은 확인할 수 없다.
- 1~3쪽 및 6쪽의 위 표 관계를 집중 검토했다. 다른 모든 본문에 대해 PDF와 문자 단위 완전 일치를 증명한 것은 아니다. 내용이 바뀐 구조 정리본이므로 향후 AI 인용은 정리본 문단을 기준으로 검증하고, 표의 의미는 PDF와 다시 대조해야 한다.

## 기계적 확인

- 기존 입력 6,849자, 정리본 6,696자: 10,000자 제한 이내.
- 기존 입력 SHA-256: `feb2ea7a0588d4a81b80c4a1ecb90cc900f0441d7a2d117c079f358a23b589ff`. 이전에 보관한 추출 파일과 바이트 단위로 같다.
- 정리본 SHA-256: `623b94611fd8471df2ba2f7d0a911240e4211195f67801a604d4513679c492af`.
- 로컬 요청 생성과 주요 수치·조건 문자열 17개, 72개 문단, 6개 페이지 구분자를 확인했다. API 네트워크 요청은 0회다.
